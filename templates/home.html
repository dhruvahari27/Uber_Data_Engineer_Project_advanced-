Real-Time Ride Booking Generator

This service simulates realistic Uber ride transactions generated using Faker and streams them live into Azure Event Hubs (Kafka protocol). From there, the events are ingested into Azure Databricks Delta Live Tables following the Medallion Architecture (Bronze → Silver OBT → Gold Star Schema).
